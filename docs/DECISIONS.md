# 当前本地交付的架构决策

日期：2026-10-13。前提：用户确认改用当前客户端，并在隔离/双端条件尚未准备时先交付本地开发与测试。所有测试配置与原客户端能力分开。

## ADR-001：原生实例路线

当前样本哈希不同于上游 PH 已知二进制。未取得获准国服启动/认证/网络对象证据，也没有隔离系统，选择保留 BLOCKED。只提供房间控制和 host 契约/合成 harness。代价是不能提供原客户端联机。取得真实地图加载、出生和网络入口证据后再评估原生运行接口；不迁移 PH 位移或猜消息号。

## ADR-002：独立身份与凭据

选择独立 Web 玩家和单独管理员表/会话，账号内部 ID 与本地整数游戏映射分离。随机邀请令牌只存 SHA-256，密码用标准库 scrypt N=32768/r=8/p=3，随机盐，管理员 TOTP 且拒绝时间步重放。此参数为 [OWASP scrypt 备选配置](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#scrypt)之一；Argon2id 尚未安装且本地版本优先保持无依赖。未来部署时重新测算成本并支持密码哈希升级；绝不将 Web 密码哈希自动等同国服认证兼容。

## ADR-003：唯一数据库主源

本地控制面使用一个 SQLite WAL 数据库、foreign_keys、BEGIN IMMEDIATE、FULL 同步和显式 schema v1。选择依据是单机、小规模可复现、标准库和已运行并发测试。上游独立数据库仅供上游测试，不与当前账号/钱包双写。PostgreSQL/多节点生产部署未实现；迁移要停写、对账、核对安全版本和已提交操作，另行评审。

## ADR-004：幂等、资产和 outbox

命令按 actor scope/key/request 摘要唯一，余额/库存/不可改写流水/outbox/成功审计同事务。响应丢失重试返回原结果；通知只重试事件，不能重做资产。选择 savepoint 做预览与批量目标隔离；目标列表一次冻结，成功子项不重发。通知 sender 必须按 event_key 去重，并显式确认才算送达。当前没有原客户端 sender，保持 PENDING。

## ADR-005：执行环境与监听

已验证 Windows / Python 3.12.14；独立控制面只用标准库。管理接口强制回环，Host/Origin/JSON 请求校验、Bearer 内存会话、有界线程/体积/速率。隔离 Windows、HTTPS 私网、跨家庭网络、Linux 实机和游戏运行均未驗证。CI 提供 Windows/Ubuntu 回归，不用配置存在冒充已运行结果。

## ADR-006：规则与冻结

合成 test-only-v1 与默认 cn-current-unverified 分离，数据库记住 profile 并拒绝混用。测试 NZ/GP 范围、4 席、500 GP 商品和100 GP 奖励都是测试规格。开始时冻结地图/目录/revision/玩家安全版本和未到期装备；后续装备对下局生效。UTC Unix 秒统一期限，不捏造原版难度/概率/掉率。

## ADR-007：制裁与租约

认证/命令/查询检查账号状态、有效制裁和安全版本。停用/重置/踢下线/封禁撤销会话、释放本地席位并失去当前局奖励资格，生成安全 outbox；其他成员继续。真实节点传播未接入，不显示已确认下线。合成实例租约 30 秒、每 5 秒维护；续租需节点身份/epoch，分区和失联拒绝继续授权。这是本地策略，需要实机协议证实后重验。

## ADR-008：备份与前向恢复

SQLite backup 到新文件并检查 integrity；禁止覆盖式恢复命令。代码回滚保留新资产/制裁/审计/outbox，旧会话不能复活，补偿用关联新记录，不删已提交流水。自动化验证备份一致性，完整隔离恢复/跨节点审计和生产密钥保护仍待验证。

## ADR-009：2026-10-14 技术栈迁移

按项目 nz-development skill 和用户确认，将旧原生页面、标准库 HTTP、SQLite 改为 React/TypeScript/shadcn/ui、Django 5.2 和 MySQL。ADR-002 的独立身份、密码格式与 MFA 继续保持，ADR-003/005/008 中旧技术栈描述作为历史保留，由本条取代。

业务逻辑通过 Django ORM 与 migrations 管理；固定部署锁记录的 SELECT FOR UPDATE 保留原本地串行事务语义，暂不增加多节点或并行写吞吐设计。MySQL 强制约束和触发器保护唯一键、余额与不可改写历史。预览和批量子项继续使用保存点，当前/合成/自动化测试库分离。

Windows 使用仓库 runtime 下独立 MySQL 实例，不接管系统服务。配置读取环境及忽略的 .env.local。Waitress 单进程回环服务与每五秒维护进程分离。前端同源提供，Bearer 只存内存，重试冻结实际 HTTP payload 及幂等键。

SQLite 仅用于显式只读导入源和迁移夹具；目标空业务库、schema v1、profile、外键与逐行数据必须核对。备份改为一致性 MySQL SQL 导出，在临时库实际恢复并摘要对账。仍禁止自动覆盖式恢复；迁移后出现新写入必须先停写、保留和对账才能回退。

## ADR-010：指定测试管理员与工作台改版

用户明确要求一个可重复固定测试验证码账号，以及另一个仅以指定密码登录的管理员。两种例外都只绑定服务端配置的单个账号 ID、合成数据库和 synthetic profile；不能扩展到普通管理员或当前 profile。免码只作用于登录，高风险权限再认证继续执行；短密码只通过专用测试创建命令接受，普通账号策略保持不变。私人配置和凭据不入库到 Git，配置安装失败回滚账号与审计。

按用户指定设计 skill 审计现有后台，保留 NZ 标识和 shadcn/ui 功能结构，采用中性色、绿色语义主色、明暗主题、可访问表单及窄屏导航。指标均来自实际读模型，技术详情折叠但可查看。桌面公开登录页 Lighthouse 与真实已登录浏览器业务验证分别记录，不用页面评分替代业务或真实游戏验收。
