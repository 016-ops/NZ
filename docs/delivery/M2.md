管理员采用密码加 TOTP、15 分钟会话；玩家会话 60 分钟。新登录撤销旧玩家会话并释放本地席位。所有制裁检查独立于账号激活状态，解封一条不会移除另一条有效制裁。

本地用户与后台 ID 是服务自己分配的映射，不绑定 QQ，不保存腾讯凭据。初始 Owner 由交互命令创建，普通注册不能获得管理角色。第一版没有修改/停用管理员的接口，因此不能通过普通流程停用最后一个 Owner；其他后台角色的授权逻辑已做负面测试，管理员生命周期管理待后续补齐。

## 安全与边界

慢哈希为标准库 scrypt：N=32768、r=8、p=3，随机 16 字节盐；选择见 ADR-002。MFA 密钥和会话验证数据属于私人数据库，后台查询/审计不返回密码或 token。数据库与 MFA 资料依赖操作系统用户文件权限保护，尚未交付密钥保险库或多主机管理。

HTTP 默认只监听 `127.0.0.1`，检查 Host/Origin、要求 JSON 和自定义请求头；令牌只存在页面内存；无跨域授权、无自动保存密码。接口限制体积/并发/速率，页面用文本节点输出内容。

测试包含 10 次并发使用单次邀请、同键重放、新账号隔离、会话撤销、永久/限时/多条制裁、服务重建后的状态保持、玩家/不同管理员角色直调接口拒绝，以及真实 HTTP 的 CSRF/Host/Origin 负面用例。结果见 `evidence/automated-tests.json`。
